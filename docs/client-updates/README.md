# TAP Client Hub Client Update Source Records

Create an internal source record before a project owner sends a client update. Each record must include:

- Reporting date, milestone, integrated commit, and verified environment.
- Client-visible completed behavior and test evidence.
- Work underway, next step, and client action required.
- Client-relevant blockers, limitations, and delivery status.
- Details that must not be communicated, including credentials, internal branches, secret configuration, and unverified conclusions.

The project owner approves wording and sends the external message. A client update never substitutes for release evidence.
